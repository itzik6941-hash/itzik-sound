ITZIK SOUND — מדריך מצב והפעלה

הפעלה מקומית
1. התקן Node.js 20 ומעלה.
2. התקן תלויות עם npm install.
3. הגדר משתני סביבה בשרת (לעולם אל תעלה .env ל-GitHub):
   SUPABASE_URL
   SUPABASE_ANON_KEY או SUPABASE_PUBLISHABLE_KEY
   ROEX_API_KEY (נדרש ל-RoEx)
   OPENAI_API_KEY (נדרש ל-ITZKO ולרעיונות)
4. הרץ npm start ופתח http://localhost:3000.

יכולות הפעילות בקוד
- Supabase Auth (אימייל/סיסמה ו-Google), טעינת פרויקטים, העלאת מקור, פתיחה ומחיקה לאחר אישור.
- Waveform ונגן, ייצוא WAV ו-MP3. ייצוא משתמש בשרשרת המיקס המקומית כאשר היא מכוונת.
- מיקסר סטריאו עם Gain, Pan, Mute, EQ, Compressor, Reverb, Delay, Stereo Width,
  Master, A/B, Meter, Reset ושמירת/שחזור הגדרות בפרויקט.
- RoEx Mix Enhance Preview; Mix Enhance מלא מחייב אישור מפורש לפני הפעלה/שליפה.
- RoEx Mastering Preview; שליפת מאסטר מלא מחייבת אישור מפורש לפני קריאת השרת.
- רעיונות מוזיקליים דרך OpenAI. ITZKO יכול לקבל מדידות אות מקורבות שמחושבות בדפדפן;
  קובץ האודיו עצמו אינו נשלח ל-OpenAI.
- ניתוח תדר מחזורי מקורב והשוואת Reference (מדידות אות מקורבות, לא LUFS תקני).
- עברית ואנגלית בלבד; RTL/LTR נקבע לפי השפה.

הגנות וחיובים
- מפתחות RoEx/OpenAI נשארים בצד השרת. הדפדפן מקבל רק Supabase Publishable/Anon key.
- בקשות Mix Enhance מלא ומאסטר מלא מציגות אישור מפורש. אין בדיקת יתרת קרדיטים דרך API בקוד;
  יש לבדוק יתרה בלוח הבקרה של RoEx לפני הפעלה. אין להפעיל Auto Top-Up ללא החלטה עצמאית.
- השרת מונע ניסיון שליחה כפול לאותה שליפת מאסטר מלא או Mix Enhance בתוך תהליך שרת חי.
- קישורי תוצאה מ-RoEx אינם מועתקים כרגע לאחסון הפרויקט, והם זמניים לפי תנאי השירות.
- נדרש להגדיר RLS והרשאות Storage נכונות ב-Supabase; הקובץ הזה אינו מכיל סכמת מסד נתונים
  או מדיניות RLS ולכן אין להסיק מהבדיקות המקומיות שהרשאות Production אומתו.

בדיקות
- npm test מריץ בדיקות Node עם Mock; הבדיקות אינן מתקשרות ל-RoEx, ל-OpenAI או ל-Supabase אמיתי.
- בדיקות Syntax: node --check server.js, public/app.js, public/mixer.js.
- בדיקת Production מחייבת חשבון, משתני סביבה ופרויקט בדיקה ייעודי. אין להשתמש בפרויקטי משתמש
  קיימים לבדיקות מחיקה או פעולות בתשלום.

מגבלות ידועות
- תיקון Pitch אוטומטי אינו מחובר. הכלי מזהה תדר דומיננטי משוער בלבד ואינו מתקן או מייצא Pitch.
- המיקסר עובד כרגע על קובץ סטריאו יחיד. Solo, ערוצים נפרדים, שינוי/סידור שרשרת אפקטים וייבוא Stems
  אינם זמינים כי אין בפרויקט ערוצי stems.
- העלאת Reference דורשת פרויקט שמור. השוואת תחומי התדר ורוחב הסטריאו היא קירוב טכני בלבד.
- בדיקת יתרת הקרדיטים של RoEx, יציבות שירותי צד שלישי, RLS, והעלאה/שמירת תוצאה ב-Supabase
  דורשות בדיקה בסביבה המחוברת לחשבון; לא הורצו כאן פעולות כאלה.
