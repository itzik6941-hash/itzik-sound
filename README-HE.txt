ITZIK SOUND - עדכון חשבונות ושמירת פרויקטים בענן

מה חדש:
- התחברות והרשמה עם אימייל וסיסמה.
- התחברות עם Google דרך Supabase.
- כל משתמש רואה רק את הפרויקטים שלו.
- קובצי אודיו נשמרים באחסון פרטי של Supabase.
- פתיחת פרויקט מורידה את קובץ האודיו מהענן ומחזירה אותו לנגן.
- ייצוא WAV ו-MP3 נשאר זמין לקובץ המקורי.

הגדרות Render הנדרשות (Environment):
SUPABASE_URL=https://yrwndxchugyuzgfgaqsl.supabase.co
SUPABASE_ANON_KEY=מפתח Publishable שמתחיל ב-sb_publishable_

הערות אבטחה:
- בדפדפן נחשפים רק Project URL ומפתח Publishable ציבורי.
- אין להוסיף service_role או Secret key למשתני הקוד שנשלחים לדפדפן.
- הפרטיות נאכפת באמצעות Row Level Security והרשאות Storage ב-Supabase.

הפעלה מקומית:
1. התקן Node.js.
2. הגדר את שני משתני הסביבה למעלה במערכת או בקובץ .env מקומי (אין להעלות .env ל-GitHub).
3. הרץ npm install ואז npm start.
4. פתח http://localhost:3000.

חשוב:
- בהרשמה באימייל ייתכן שתידרש לחיצה על קישור אישור שנשלח לאימייל.
- Google OAuth זמין למשתמשים שהוגדרו כ-Test users כל עוד אפליקציית Google נמצאת במצב Testing.
- כרגע מגבלת העלאת קובץ בפרויקט היא 50MB, בהתאם להגדרת ה-bucket שנוצרה ב-Supabase.
- Mix AI מחובר ל-RoEx ומחזיר Preview; מאסטרינג AI מחובר ליצירת Preview ולשליפת מאסטר מלא. שליפת מאסטר מלא עשויה לצרוך קרדיטים ומחייבת אישור מפורש בממשק.
- תיקון זיופים, רעיונות מוזיקליים וסטודיו רפרנסים עדיין מציגים ממשק הכנה ואינם מבצעים עיבוד.
- ממשק מלא זמין בעברית ובאנגלית. שפות נוספות הוסתרו עד להשלמת התרגום.
- קובצי הפרויקטים הישנים שהיו רשומים רק בדפדפן לא יועברו אוטומטית לענן; יש להעלות אותם מחדש לאחר התחברות.
